# Basic Chatbot

## CodeAlpha Python Programming Internship — Task 4

A simple rule-based chatbot developed using Python. The chatbot accepts user messages and provides predefined responses based on the user's input.

## Features

* Responds to common greetings
* Answers simple questions
* Provides predefined responses
* Uses a function to process user input
* Uses `if-elif-else` statements
* Uses a `while` loop for continuous conversation
* Allows the user to exit by typing `bye`
* Runs completely in the console

## Technologies Used

* Python
* Functions
* If-elif-else statements
* While loop
* String handling
* User input/output

## Supported Messages

The chatbot can respond to:

* `hello`
* `how are you`
* `what is your name`
* `what can you do`
* `thank you`
* `good morning`
* `good night`
* `bye`

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: python chatbot.py


5. Type a message and press Enter.
6. Type `bye` to exit the chatbot.
